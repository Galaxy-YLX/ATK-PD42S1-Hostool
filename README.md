# ATK_PD42S_V1.0

正点原子PD42S1闭环步进电机上位机Linux版

## 创建原因：

这个项目的创建缘由是当我购买正点原子PD42S1步进电机用于校电赛之后，在使用上位机进行调试时发现官方提供的上位机exe在我的 Fedora Linux 设备中无法正常使用（即使我使用了Wine等兼容性运行措施，我还是无法点开它，很明显，wine没有奏效）。我本人很排斥使用虚拟机运行的方案（当然不是因为我没装，好吧，其实就是没装），虚拟机操作调试任务太反人类，操作通过虚拟机，虚拟机连接串口设备线，这一流程复杂并且占用了大量系统资源（它原本只是一个简单的上位机而已），为了一个简单的上位机在系统里再虚拟运行win，这绝对是彻底的噩梦，很明显，最简单的方式莫过于使用AI来制作上位机软件来彻底解决这个问题。

与此同时，我也在通过这个项目来不断补全我的VScode的使用水平，在这个项目中，我首次使用了Git用于项目树管理，以及将Git与Github联动起来完成云端同步存档，为日后的多人协同开发积累经验，这个项目也会是我的第一个在Github上开源的项目（顺便也学学怎么开源），通过这个项目，我初步学会了使用一套完整的开发链路，受益匪浅。同时也要感谢开源社区及广大B站教学视频，让整个开发链路的学习变得无比简单，甚至还特地有鼠标化操作Git的教程，没有这些工作，这些东西的学习肯定会花更多的时间及精力。

## 计划实现的功能：

第一部分：原本上位机功能的复刻，即自定义协议指令的下发与读取（基础调试功能）

第二部分：增加多机协同功能，支持快捷对总线上多个电机的指令下发（进阶调试）

第三部分：增加任务表系统，支持按计划串行执行指定程序（任务队列系统）
